## 📋 О проекте

**CLC** — это полнофункциональное веб-приложение для **Местной Религиозной Организации Церковь Христиан Веры Евангельской «Церковь Христианской Жизни»** города Красноярска.

Платформа объединяет в себе образовательные, коммуникационные и медийные возможности для духовного развития общины.

---

## ⚡ Ключевые возможности

| Область | Возможности |
|:--------|:------------|
| 🎥 **Трансляции** | Автоматическое определение начала воскресных служений с переключением между Rutube и YouTube |
| 🗺️ **Духовный путь** | Система уровней в стиле Duolingo с 8 типами контента и визуальным прогрессом |
| 💬 **Чаты** | Личные сообщения с компрессией, хешированием и счетчиком непрочитанных |
| 📚 **Библиотека** | Видео, планы чтения Библии, события, детский раздел с мультфильмами и играми |
| 🙏 **Молитвы** | Публичные и приватные молитвенные нужды с счётчиком поддержки |
| 💝 **Пожертвования** | Онлайн-пожертвования с генерацией уникальных платежных ID |
| 🔔 **Уведомления** | Web Push-уведомления о начале трансляций и событиях |
| 📱 **PWA** | Установка приложения на мобильные устройства |
| 👤 **Профиль** | Прогресс, статистика, настройки, история активности |

## ✨ Текущий функционал

### 🏠 Главная страница
- Snap-scroll полноэкранными секциями
- Карусель новостей и событий
- Стих дня
- Таймер обратного отсчёта до воскресного служения (11:00 GMT+7)
- Режим «В ЭФИРЕ» (воскресенье 11:00–14:00)
- Секция новостей с карточками
- Аудиоподкаст (Podster.fm)

### 📡 Видео API
- Rutube — основная платформа
- YouTube — резервная
- Автоматическое переключение при недоступности

### 📚 Библиотека
- **Видео** — каталог с категориями, просмотрами, рекомендациями
- **Планы чтения Библии** — многодневные планы с прогрессом
- **События** — календарь с фильтрами, регистрация, лимит участников
- **Детский раздел**

### 🙏 Молитвенный центр
- Публичные и приватные молитвенные нужды
- Счётчик поддержки («Я молюсь»)
- Отметка «Отвечено»
- Личный кабинет молитв

### 🔐 Аутентификация и профиль
- Регистрация, вход, выход
- Редактирование профиля (имя, фамилия, email)
- Смена пароля
- Статистика в личном кабинете:
  - Количество молитвенных нужд
  - Количество завершённых планов чтения
  - Количество зарегистрированных событий

### 🔔 Push-уведомления и PWA
- Веб-уведомления о начале трансляций и событиях
- Service Worker для офлайн-доступа
- Установка приложения на мобильные устройства

## 🚀 Быстрый старт

### Требования
- Python 3.12+
- pip

### Установка

```bash
# Клонирование репозитория
git clone <URL> CLC
cd CLC

# Создание виртуального окружения
python -m venv venv

# Активация (Windows)
venv\Scripts\activate

# Активация (Linux/Mac)
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Создание файла .env
cp .env.example .env

# Применение миграций
python manage.py migrate

# Создание суперпользователя
python manage.py createsuperuser

# Запуск сервера
python manage.py runserver
Доступ
Приложение	http://127.0.0.1:8000/
Админ-панель	http://127.0.0.1:8000/admin/
