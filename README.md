## 📋 О проекте

CLC — это веб-приложение для **Местной Религиозной Организации Церковь Христиан Веры Евангельской «Церковь Христианской Жизни»** города Красноярска. Приложение объединяет в себе:

- 🎥 **Онлайн-трансляции** воскресных служений с автоматическим определением расписания
- 🗺️ **Духовный квест** — система уровней и прогресса (геймификация) для вовлечения общины
- 📚 **Библиотека** — видео, планы чтения Библии, события, детский раздел
- 👤 **Профиль пользователя** — личный кабинет с достижениями и прогрессом
- 📱 **Мобильная адаптация** — полноценный mobile-first дизайн с нижним навигационным баром

## 🛠 Технологический стек

### Backend
| Технология | Назначение |
|---|---|
| **Python 3.10+** | Основной язык сервера |
| **Django 4.2** | Web-фреймворк (MTV-архитектура) |
| **SQLite** | База данных (разработка) |
| **requests** | HTTP-клиент для API Rutube/YouTube |
| **pytz / zoneinfo** | Работа с часовыми поясами (GMT+7, Красноярск) |
| **Pillow** | Обработка изображений (ImageField) |

### Frontend
| Технология | Назначение |
|---|---|
| **Tailwind CSS (CDN)** | Утилитарный CSS-фреймворк |
| **Vanilla CSS** | Кастомная дизайн-система «Midnight Gold» |
| **Vanilla JavaScript** | Интерактивность, карусель, таймер, snap-скролл |
| **Google Fonts** | Inter, Public Sans |
| **Material Symbols** | Иконки интерфейса |
| **Font Awesome 6** | Дополнительные иконки |

### Дизайн-система «Midnight Gold»
Палитра основана на сочетании глубокого тёмно-синего (`#1a1f36`) и тёплого золота (`#c9a84c`) на кремовом фоне (`#f5f0e8`). Спокойные, чистые цвета с акцентом на читаемость и духовную эстетику.

## ✨ Текущий функционал

### 🏠 Главная страница
- **Snap-scroll** — полноэкранные секции с плавной прокруткой
- **Карусель** — информационные слайды о церкви
- **Таймер обратного отсчёта** — до ближайшего воскресного служения (11:00 GMT+7)
- **Встроенный видеоплеер** — автоматическое определение трансляции Rutube/YouTube
- **Режим «В ЭФИРЕ»** — автоматически активируется во время служения (воскресенье 11:00–14:00)

### 📡 Video API (Мульти-платформенный)
- **Rutube** — основная платформа (API с поиском по ключевым словам)
- **YouTube** — резервная платформа (парсинг HTML страницы `/streams`)
- **Fallback-логика** — при недоступности Rutube автоматически переключается на YouTube
- **Кэширование** — `@cache_page` для снижения нагрузки

### 🗺️ Духовный квест (Геймификация)
- Система уровней: «Основы веры», «Духовный рост», «Служение», «Лидерство» и др.
- Визуальная карта прогресса с 8 типами зданий
- Опыт и достижения за выполнение заданий
- Прогресс-бар и процент выполнения

### 📚 Библиотека
- **Видео** — каталог с категориями, просмотрами, рекомендациями
- **Планы чтения Библии** — многодневные планы с отслеживанием прогресса
- **События** — календарь с фильтрами по типу и месяцу, регистрация
- **Детский раздел** — мультфильмы, уроки, игры, поделки, песни (5 типов контента)

### 🔐 Аутентификация и профиль
- Регистрация, вход, выход
- Редактирование профиля и смена пароля
- Личный кабинет с достижениями и историей прогресса

### 🎨 UI/UX
- Mobile-first дизайн с нижним навигационным баром (Telegram-style)
- Адаптивный десктопный header с навигацией
- Бургер-меню для мобильных устройств
- Модальные окна, скелетоны загрузки, микро-анимации
- Open Graph метатеги для социальных сетей

## 🚀 Быстрый старт

### Требования
- Python 3.10+
- pip

### Установка

```bash
# Клонирование репозитория
git clone <URL> CLC
cd CLC

# Создание виртуального окружения
python -m venv venv

# Активация (Windows)
venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt

# Применение миграций
python manage.py migrate

# Создание суперпользователя (для админки)
python manage.py createsuperuser

# Запуск сервера разработки
python manage.py runserver
```

### Доступ
- **Приложение:** http://127.0.0.1:8000/
- **Админ-панель:** http://127.0.0.1:8000/admin/
