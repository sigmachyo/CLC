## 📋 О проекте

**CLC** — это полнофункциональное веб-приложение для **Местной Религиозной Организации Церковь Христиан Веры Евангельской «Церковь Христианской Жизни»** города Красноярска.

Платформа объединяет в себе образовательные, коммуникационные и медийные возможности для духовного развития общины.

---

## ⚡ Ключевые возможности

| Область | Возможности |
|---------|-------------|
| 🎥 **Трансляции** | Автоматическое определение начала воскресных служений с переключением между Rutube и YouTube |
| 🗺️ **Духовный путь** | Система уровней в стиле Duolingo с 8 типами контента и визуальным прогрессом |
| 💬 **Чаты** | Личные сообщения с компрессией, хешированием и счетчиком непрочитанных |
| 📚 **Библиотека** | Видео, планы чтения Библии, события, детский раздел с мультфильмами и играми |
| 🙏 **Молитвы** | Публичные и приватные молитвенные нужды с счётчиком поддержки |
| 💝 **Пожертвования** | Онлайн-пожертвования с генерацией уникальных платежных ID |
| 🔔 **Уведомления** | Web Push-уведомления о начале трансляций и событиях |
| 📱 **PWA** | Установка приложения на мобильные устройства |
| 👤 **Профиль** | Прогресс, статистика, настройки, история активности |

## 🛠 Технологический стек

### Backend

| Технология | Назначение |
|:-----------|:-----------|
| **Python 3.12+** | Основной язык сервера |
| **Django 4.2** | Web-фреймворк (MTV-архитектура) |
| **SQLite / PostgreSQL** | База данных |
| **django-jazzmin** | Кастомизация админ-панели |
| **requests** | HTTP-клиент для API Rutube/YouTube |
| **Pillow** | Обработка изображений |
| **python-dotenv** | Управление переменными окружения |

### Frontend

| Технология | Назначение |
|:-----------|:-----------|
| **Tailwind CSS** | Утилитарный CSS-фреймворк |
| **Vanilla CSS** | Кастомная дизайн-система «Midnight Gold» |
| **Vanilla JS** | Интерактивность, карусель, таймер, snap-скролл |
| **Material Symbols** | Иконки интерфейса |
| **Font Awesome 6** | Дополнительные иконки |

Установка на устройство

🚀 Быстрый старт
Требования
Python 3.12+

pip

Установка
bash
# Клонирование
git clone <URL> CLC
cd CLC

# Виртуальное окружение
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # Linux/Mac

# Зависимости
pip install -r requirements.txt

# Переменные окружения
cp .env.example .env

# Миграции
python manage.py migrate

# Суперпользователь
python manage.py createsuperuser

# Запуск
python manage.py runserver
Доступ
Приложение	http://127.0.0.1:8000/
Админ-панель	http://127.0.0.1:8000/admin/
Переменные окружения (.env)
env
SECRET_KEY=your-secret-key-here
DEBUG=True
BIBLE_API_KEY=your-bible-api-key
