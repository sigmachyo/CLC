📋 О проекте
KCLC — это полнофункциональное веб-приложение для Местной Религиозной Организации Церковь Христиан Веры Евангельской «Церковь Христианской Жизни» города Красноярска. Платформа объединяет в себе образовательные, коммуникационные и медийные возможности для духовного развития общины.

Ключевые возможности:
🎥 Онлайн-трансляции — автоматическое определение времени начала и завершения воскресных служений с переключением между Rutube и YouTube

🗺️ Карта духовного пути — система уровней в стиле Duolingo с 8 типами контента и визуальным прогрессом

💬 Система личных чатов — обмен сообщениями между пользователями с компрессией и хешированием

📚 Мультимедийная библиотека — видео, планы чтения Библии, события, детский раздел с мультфильмами и играми

🙏 Молитвенный центр — публичные и приватные молитвенные нужды с счётчиком поддержки

💝 Пожертвования — онлайн-пожертвования с генерацией уникальных платежных идентификаторов

🔔 Push-уведомления — веб-уведомления о начале трансляций и событиях

📱 PWA-поддержка — установка приложения на мобильные устройства

👤 Личный кабинет — прогресс, статистика, настройки, история активности

🚀 Быстрый старт
Требования
Python 3.12+

pip

Установка
bash
# Клонирование репозитория
git clone <URL> CLC
cd CLC

# Создание виртуального окружения
python -m venv venv

# Активация (Windows)
venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt

# Создание файла .env (скопируйте из .env.example)
cp .env.example .env

# Применение миграций
python manage.py migrate

# Создание суперпользователя (для админки)
python manage.py createsuperuser

# Запуск сервера разработки
python manage.py runserver
